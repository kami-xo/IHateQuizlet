## ℹ️ Overview

### What is I Hate Quizlet?

I Hate Quizlet (IHateQuizlet) is a simple Python application that acts like a multiple choice practice quiz. It is meant to emulate Quizlet's quiz/test modules.

### Why I Hate Quizlet?

I got tired of Quizlet moving away from the multiple choice problems and having you spell words. Especially for my BIOL class which, I'm not remembering how to spell 
```
Bremia krungthepmahanakhonamonrattanakosinmahintharayuthayamahadilokphopnoppharatratchathaniburiromudomratchaniwetmahasathanamonpimanawatansathitsakkathattiyawitsanukamprasitnonopsis
```
(yes that is a real species name). 

I also got very tired of Quizlet randomly slapping me with in-app-purchases so I decided this would be a great oppurtunity to learn Python and build my own Quizlet app.
